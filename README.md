# PhyS Project Page

Static GitHub Pages site for "Distilling Physical Priors into Streaming World Models".

Local entry point: `index.html`

## Local preview

```bash
python3 -m http.server 8090
```

Open `http://127.0.0.1:8090/` in a browser.

The interactive comparison section contains 15 matched ten-second examples
across Self-Forcing, Rolling-Forcing, and Causal-Forcing. Each comparison pairs
the forcing baseline with the corresponding `+PhyS` generation. Videos are
stored under `assets/videos/`; lightweight poster frames are under
`assets/posters/`.
